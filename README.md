# 💎 Diamond Price Prediction & Market Segmentation

A Machine Learning project that predicts the price of a diamond based on its characteristics and identifies its market segment using K-Means clustering.

## 📌 Project Overview

The project uses machine learning techniques to:

* Predict diamond prices using regression algorithms.
* Compare the performance of multiple regression models.
* Tune the best-performing model using hyperparameter optimization.
* Identify diamond market segments using K-Means clustering.
* Deploy the models using a Streamlit web application.

## 📊 Dataset

The dataset contains information about diamonds and their characteristics.

### Important Features

| Feature   | Description                                             |
| --------- | ------------------------------------------------------- |
| `carat`   | Weight of the diamond                                   |
| `cut`     | Quality of the diamond cut                              |
| `color`   | Diamond color grade                                     |
| `clarity` | Clarity grade                                           |
| `depth`   | Total depth percentage                                  |
| `table`   | Width of the diamond's top relative to its widest point |
| `x`       | Length in mm                                            |
| `y`       | Width in mm                                             |
| `z`       | Depth in mm                                             |
| `price`   | Diamond price                                           |

## 🧹 Data Preprocessing

The following preprocessing techniques were performed:

* Checked missing values and duplicate records.
* Examined feature distributions and outliers.
* Applied feature engineering.
* Created `volume` using:

```python
volume = x × y × z
```

* Applied ordinal encoding to:

  * `cut`
  * `color`
  * `clarity`
* Applied appropriate transformations where required.
* Prepared separate feature sets for regression and clustering.

## 🤖 Regression Models

The following models were trained and compared:

* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor
* K-Nearest Neighbors Regressor
* XGBoost Regressor
* Artificial Neural Network (ANN)

### Evaluation Metrics

Models were evaluated using:

* MAE — Mean Absolute Error
* MSE — Mean Squared Error
* RMSE — Root Mean Squared Error
* R² Score

## ⚙️ Hyperparameter Tuning

Hyperparameter tuning was performed to improve the selected regression model.

Techniques used:

* `RandomizedSearchCV`
* `GridSearchCV`

The tuned model was evaluated on the test dataset before deployment.

## 📊 Market Segmentation

K-Means clustering was used to group diamonds with similar characteristics.

### Steps

1. Select relevant clustering features.
2. Scale the features.
3. Determine the optimal number of clusters using:

   * Elbow Method
   * Silhouette Score
4. Train the K-Means model.
5. Analyze cluster centroids.
6. Assign meaningful market segment names.

Example segments:

* Affordable Small Diamonds
* Mid-range Balanced Diamonds
* Premium Heavy Diamonds

> Cluster numbers are generated by K-Means and do not have an inherent meaning. The market segment names are assigned after analyzing the characteristics of each cluster.

## 📱 Streamlit Application

The project is deployed as an interactive Streamlit application with two main modules.

### 🎯 1. Price Prediction

Users enter:

* Carat
* Cut
* Color
* Clarity
* Length (`x`)
* Width (`y`)
* Height (`z`)

The application predicts the estimated diamond price and displays it in **Indian Rupees (INR)**.

### 📊 2. Market Segment Prediction

The same diamond details are used to predict the market segment.

The application displays:

* Cluster number
* Corresponding market segment
